## 已完成(第二轮:生成版质量差,查出哪些是我们的错)

逐对看 v14 的图,生成版难看的原因分成我们的错和模型的错;我们的错都按通用规则改,不针对某个网站:

- 压在一节上、却不在任何一节里的层(vercel 首屏的集装箱 canvas 和 "READ THE RECAP" 在 `<body>` 末尾的固定定位层里):换节时没藏,压在生成的内容上;模型也不知道它。现在算它压着的那一节的(`data-part`),一起读、一起藏。vercel #1 的绳子穿过导航栏,随后按重叠规则排除。
- 给模型的图和它用上的图不一样(raycast 的键盘是 SVG 里套 HTML,单独渲染塌成一列 F 键标签):内联 SVG 单独截一张比一比,不一样就给截图;视频、canvas 改为单独截(原来是整页截图里裁一块,带着叠在上面的文字);单独截下来什么都看不见的图(叠着交替淡入的 logo 里藏着的那个)不算内容。
- 用 HTML 搭的示意图拆成了一条条标签:页面标成 `role="img"`、或 `aria-hidden` 而文字别处读不到的,整个截成一张图。
- 加载时整页截图让 stripe 的脚本量到 5px 宽,示意图缩成 1/56(原版图里就是空的):脚本开着时我们做的每件事之后都推一段页面时间,让页面把拖后的反应做完。
- 模型不知道网格和字号层级:给框的横向位置、页面内容栏、邻节的左右边,字号体系先列各节标题和正文用的样式;原版对齐网格而生成版没对齐的(stripe #12 缩进 26px)打回重写(`grid`)。

## 待做

1. **区分"我们的错"和"模型的错"**(上一轮留下的):
   - 没有无障碍标注的示意图还是拆成文字(cal 的日历 "Mon 8:30 am"、stripe 连接图除第一排以外的部分、raycast 一节的整个应用界面)。页面不标注时,要从样子上认出"这是一张图":可以截出这一节给看图的模型,问哪些文字是图里的标签,再按 DOM 把它们归成一个个图;代价是每个候选节一次模型请求,结果不完全确定。先看更多网站里没标注的有多少再定。
   - 富文本的样式丢了:stripe 的标题是"前半句深色、后半句灰色"一段字,读成一条文字,模型不知道有两种样式,上下两节都是这种写法,生成版不是。
2. **CSS mask 画的图标**:`mask-image` 加背景色画出来的图标现在不算内容项,模型拿不到。要给它一个能用的文件(把形状和颜色合成一张 SVG 或 PNG)。
3. **iframe**:嵌入的视频、地图、表单不读成内容项,换节时也一起藏掉;跨域 iframe 在别的进程里,关脚本管不到它,它可能还在动。查这几个站和更多站点里有多少,再决定截成图还是排除含 iframe 的节。
4. **模型请求 HTTP 524**(v10 stripe #11,重试 3 次都失败,整节丢失):524 是端点前面的 Cloudflare 等了约 100 秒没收到任何字节就断开,deepseek 先长时间思考时必然触发,重试没用。根本做法:请求改成流式(`stream: true`),边生成边收,连接一直有数据就不会被断。
5. **速度**:现在主要花在模型上。deepseek 每次先想 1–2.7 万 token(60–250 秒),glm 短一些。要不要限制思考长度,得看对生成质量的影响,由人决定。
6. **标签可靠性**(之前提的 A/B/C,还没定):生成版有时不比原版差,"原版更好"的标签不一定对。
7. 更多生成模型(`GEN_MODELS`),等给模型名。
8. **伪元素画的装饰**:arc 每节之间的波浪分隔线是子元素的 `::after`(SVG 背景图),既不算背景层也不算内容项,藏节时跟着藏掉,模型又不知道它,生成版就少了这条线。伪元素没有可量的盒子,要另想办法判断它是页面的框线(留着)还是这一节的内容(交给模型)。
